# 💇 Salon Website – Responsive Beauty Salon Website

## 🌐 Live Demo
https://salone-website.netlify.app/

---

## 📌 Project Overview

Salon Website is a modern and fully responsive website designed for beauty salons, hair studios, and personal care businesses. The project focuses on creating a clean user interface, smooth user experience, and a responsive layout that works across all devices.

The website presents salon services, business information, and contact details in a structured and visually appealing layout, helping businesses showcase their services professionally online.

---

## ✨ Features

- Fully Responsive Design
- Modern Landing Page Layout
- Service Showcase Section
- Clean and Structured UI
- Smooth Hover Effects
- Contact Section
- Mobile-Friendly Navigation
- Cross-Browser Compatibility
